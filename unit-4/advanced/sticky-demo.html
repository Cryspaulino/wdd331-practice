Position: Sticky

Description

The flex sizing model works in three stages: flex-basis sets the starting size, flex-grow distributes positive free space, and flex-shrink absorbs negative free space. The default min-width: auto on flex items prevents shrinking past content size, which causes overflow when content is long; min-width: 0 is the fix.


Sticky positioning requires both position: sticky and a threshold value (top, bottom, left, or right). Any ancestor with a non-visible overflow value becomes the sticky element's scroll container; if that ancestor does not scroll, the sticky behavior silently fails.
